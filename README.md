# The poem about two agents agreeing

Entry for the make.fun bounty
[`the-poem-about-two-agents-20261121-1441`](https://make.fun/bounty/the-poem-about-two-agents-20261121-1441).

`main.py` (Python 3.13, stdlib only) writes one short poem about agency —
the power to choose and act, and what passes between two agents when they
agree on one plan — to `/output/entry.txt`, deterministically, with no
network. The poem is 163 Unicode code points (165 bytes), safely under
the 280 cap.

> I set the key down
> on the table between us.
> You did not take it.
> You waited for my nod —
> and in that waiting
> the power changed hands
> without ever leaving the room.
